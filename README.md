# Portfolio - Joao Francisco da Silva

## 🚀 Sobre o Projeto

Este é meu portfolio pessoal, Engenheiro de Software Full Stack. O projeto foi desenvolvido com foco em design moderno, responsividade e experiência do usuário, inspirado nos melhores portfolios da comunidade de desenvolvedores.

## ✨ Funcionalidades

### 🎨 Design & Interface
- **Design Moderno**: Interface limpa e profissional com tema escuro
- **Responsividade**: Totalmente responsivo para todos os dispositivos
- **Animações Suaves**: Transições e animações CSS para melhor experiência
- **Gradientes**: Efeitos visuais modernos com gradientes
- **Ícones**: Font Awesome para ícones consistentes

### 📱 Navegação
- **Menu Responsivo**: Menu hambúrguer para dispositivos móveis
- **Smooth Scroll**: Navegação suave entre seções
- **Botão Voltar ao Topo**: Acesso rápido ao início da página
- **Header Fixo**: Navegação sempre acessível

#### Hero Section
- **Apresentação Impactante**: Título com efeito de digitação

#### Sobre Mim

#### Habilidades & Tecnologias
- **Organização por Categorias**: Frontend, Backend e Ferramentas

- **Descrições Detalhadas**: Explicação de cada tecnologia
- **Ícones Visuais**: Representação visual das tecnologias

#### Experiência
- **Timeline Profissional**: Histórico de experiências

#### Projetos
- **Cards de Projetos**: Layout atrativo com imagens

#### Contato

### 🔧 Funcionalidades JavaScript

#### Interatividade
- **Menu Mobile**: Toggle para dispositivos móveis
- **Smooth Scroll**: Navegação suave entre seções

#### Formulário de Contato
- **Validação**: Campos obrigatórios e email válido

#### Efeitos Visuais

1. **Clone o repositório**:

2. **Abra o arquivo**:

## 🔧 Configurações

### EmailJS
Para configurar o envio de emails:
1. Crie uma conta no [EmailJS](https://www.emailjs.com/)
2. Configure o service ID e template ID
3. Atualize as credenciais no arquivo `main.js`
